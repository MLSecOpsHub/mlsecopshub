# MLSecOpsHub

**MLSecOps and AI security.** MLSecOpsHub is the practice behind [The MLSecOps Hacker](https://themlsecopshacker.com) newsletter, the [awesome-MLSecOps](https://github.com/MLSecOpsHub/awesome-MLSecOps) list and [awesomemlsecops.com](https://awesomemlsecops.com).

- **Consulting:** [AI security assessments, MLSecOps pipeline hardening, AI governance readiness](https://mlsecopshub.com/services) (EU AI Act, Cyber Resilience Act, NIST AI RMF, ISO/IEC 42001). Fixed-scope, quoted after a 30-minute call.
- **Data:** the [Agentic Attack Index](https://mlsecopshub.com/data), an open CC BY 4.0 dataset of documented prompt injection, AI agent and MCP incidents. Contribute in [agentic-attack-index](https://github.com/MLSecOpsHub/agentic-attack-index).
- **Readiness checklists:** [EU AI Act](https://mlsecopshub.com/readiness/eu-ai-act) · [Cyber Resilience Act](https://mlsecopshub.com/readiness/cyber-resilience-act) · [NIST AI RMF](https://mlsecopshub.com/readiness/nist-ai-rmf) · [ISO/IEC 42001](https://mlsecopshub.com/readiness/iso-42001)
