MLSecOpsHub is the organization behind The MLSecOps Hacker newsletter and the awesome-MLSecOps list. From today it also has a home for the consulting practice: three fixed-scope services, four framework readiness pages, and a set of anonymized case notes.

## What is on the site

- [Services](/services): AI security assessment, MLSecOps pipeline hardening, and AI governance readiness. Each page lists the scope as a numbered list, the duration, what the client provides and what is delivered.
- [Readiness](/readiness): the EU AI Act, the Cyber Resilience Act, NIST AI RMF and ISO/IEC 42001, each mapped to concrete MLSecOps controls with a downloadable checklist.
- [Case notes](/case-notes): illustrative composites of engagements, structured as context, finding, fix and outcome.
- [Data](/data): the Agentic Attack Index.

## The Agentic Attack Index

The index is an open, CC BY 4.0 dataset of documented prompt injection, AI agent and Model Context Protocol incidents. Each entry records the vector, the affected product, the disclosure date, the impact, the fix status and a primary source. The first release covers disclosures from 2023 onward. The canonical file lives in the MLSecOpsHub GitHub organization and the [data page](/data) renders it as a sortable table.

Contributions are welcome through pull requests. Entries need a primary source.

## What stays where

The newsletter remains on Substack, and the tools, resources and glossary remain on awesomemlsecops.com. This site owns the entity, the services, original data and case notes, and nothing is mirrored between the three.
